# 🏫 Gestão de Turmas — SENAI

Este é um projeto desenvolvido para gerenciar turmas, alunos e cursos do SENAI. O sistema visa facilitar a organização das salas, controle de frequência, notas e cadastro de estudantes por modalidade de ensino.

## 🚀 Funcionalidades

* **Filtro de Turmas:** Visualização rápida das turmas por período (Manhã, Tarde, Noite).
* **Cadastro de Alunos:** Gerenciamento de matrículas, nomes e cursos técnicos/profissionalizantes.
* **Listagem Dinâmica:** Painel interativo para professores e administradores consultarem os dados de cada classe.
* **Status da Turma:** Indicadores visuais de vagas preenchidas, cursos ativos e progresso das aulas.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação das tabelas de alunos e formulários de cadastro.
* **CSS3:** Estilização com a identidade visual padrão (padrão azul/vermelho/branco do SENAI) e layout responsivo.
* **JavaScript (Vanilla):** Lógica para adicionar alunos às turmas, validação de campos e filtros de busca rápidos.

## 💻 Como Executar o Projeto

Este projeto roda inteiramente no navegador de forma simples e rápida.

1. Baixe os arquivos do repositório para o seu computador.
2. Localize o arquivo principal (geralmente `index.html`).
3. Dê um duplo clique no arquivo para abri-lo em qualquer navegador web.
